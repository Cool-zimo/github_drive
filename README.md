# 📁 GitHub Drive

> 基于 GitHub API 的虚拟文件系统 —— 把多个 GitHub 仓库变成一个统一的云端硬盘

## ✨ 特性

- **🗂️ 统一文件管理** — 关联多个 GitHub 仓库，在一个界面中管理所有文件，完全感受不到文件分散在不同仓库
- **📤 拖拽上传** — 支持拖拽文件到浏览器直接上传，大文件自动使用 Git Data API（最大支持 100MB）
- **📦 仓库创建** — 一键创建私有存储仓库，也可以关联已有的仓库
- **🔗 一键分享** — 选中文件后自动创建公开仓库 + GitHub Pages 下载页面，生成美观的分享链接
- **🔍 文件搜索** — 跨所有仓库搜索文件
- **⭐ 收藏 & 最近使用** — 快速访问常用文件
- **📂 文件操作** — 支持新建文件夹、重命名、移动、复制、删除
- **👁️ 文件预览** — 支持图片、文本、PDF 等格式的在线预览
- **🔒 纯前端** — 无需后端服务器，Token 仅存储在本地浏览器，可直接部署在 GitHub Pages
- **🧩 零依赖** — 纯 Token 登录，无需安装浏览器扩展，开箱即用

## 🚀 快速开始

### 1. 创建 GitHub Token

前往 [GitHub Settings → Tokens](https://github.com/settings/tokens/new?scopes=repo,workflow&description=GitHub+Drive) 创建一个 Personal Access Token，需要勾选以下权限：

- `repo` — 完整的仓库访问权限
- `workflow` — 用于 GitHub Pages 操作

### 2. 使用应用

- **在线使用**：将本仓库部署到 GitHub Pages 后直接访问
- **本地使用**：克隆仓库后用浏览器打开 `index.html` 即可

### 3. 登录

在登录页面输入你的 GitHub Token，点击"进入 Drive"。

> Token 仅存储在浏览器的 localStorage 中，不会上传到任何服务器。

## 📖 使用指南

### 关联/创建仓库

首次使用时，点击右上角"新建仓库"创建一个私有存储仓库，或点击侧边栏"存储仓库"旁边的 `+` 关联已有仓库。

### 上传文件

- 点击工具栏"上传文件"按钮选择文件
- 或直接将文件拖拽到文件列表区域
- 支持同时上传多个文件

### 分享文件

1. 右键点击要分享的文件（支持多选）
2. 选择"分享"
3. 输入分享名称和描述（可选）
4. 点击"创建分享"
5. 系统会自动：
   - 创建一个公开仓库
   - 复制文件到该仓库
   - 生成一个美观的下载页面
   - 启用 GitHub Pages
   - 返回分享链接

> GitHub Pages 可能需要 1-2 分钟才能生效。

### 文件管理

- **双击**文件夹进入，双击文件预览
- **右键**文件打开操作菜单（打开、下载、分享、重命名、移动、复制、收藏、删除）
- **面包屑导航**快速返回上级目录

## 🛠️ 技术架构

```
github_drive/
├── index.html              # 主页面
├── css/
│   └── style.css           # 样式
├── js/
│   ├── github-api.js       # GitHub REST API 封装
│   ├── storage.js          # 本地存储管理（Token、仓库、索引）
│   ├── file-manager.js     # 统一文件系统抽象（跨仓库）
│   ├── share.js            # 分享功能（公开仓库 + Pages）
│   ├── ui.js               # 界面渲染与交互
│   └── app.js              # 主应用入口
└── README.md
```

### 核心设计

- **虚拟文件系统**：`FileManager` 类将多个仓库的文件统一抽象，用户看到的是统一的路径，实际映射到不同仓库
- **大文件处理**：小于 1MB 使用 Contents API，大于 1MB 使用 Git Data API（Blob + Tree + Commit）
- **批量操作**：使用 Git Data API 实现单次 commit 批量上传/删除/移动
- **分享机制**：创建公开仓库 → 批量复制文件 → 生成下载页面 HTML → 启用 GitHub Pages

## 📋 注意事项

- GitHub 单文件最大限制为 100MB（通过 API）
- 仓库总大小建议不超过 1GB
- GitHub API 有速率限制（认证用户 5000 次/小时）
- 删除操作不可撤销，请谨慎操作
- Token 请妥善保管，拥有 `repo` 权限的 Token 可以访问你的所有私有仓库

## 🔐 隐私安全

- 所有数据存储在你自己的 GitHub 账户中
- Token 仅保存在浏览器本地，不会发送到任何第三方服务器
- 存储仓库默认创建为私有
- 分享时才会创建公开仓库
